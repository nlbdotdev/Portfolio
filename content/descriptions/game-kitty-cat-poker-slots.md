Kitty Kat Poker Slots Casino is a full scale android app I was commissioned to develop. It's a slot machine game based on matching poker hands with a cute cat theme.

We started with a bare bones prototype with hand drawing and a comprehensive debug mode. We then moved to final art and audio assets. From there we added platform specific items and Google Play API which included:

- An account system via Firebase, which supports Google Play, Facebook, or email login.

- A daily login reward, also using the account system.

- Google Play achievements

- In App Purchases
